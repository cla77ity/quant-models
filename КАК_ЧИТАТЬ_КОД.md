# Как читать квантовый код

Цель — не писать код самому, а **открыть любую модель и понимать, что в ней происходит**: откуда берутся данные,
как считается сигнал, сколько риска берёт стратегия и где в бэктесте может прятаться ошибка.

## 1. Любая квант-модель — это 5 шагов

```
данные  →  сигнал  →  размер позиции  →  P&L с издержками  →  метрики риска
qm/data.py      qm/portfolio.py (функция backtest)          qm/risk.py
```

Если открыл незнакомый код — сначала найди эти 5 мест. Всё остальное — детали.

## 2. Минимум Python, чтобы читать

| Что видишь | Что это значит |
|---|---|
| `x = 0.10` | переменная `x` теперь равна 0.10 |
| `[0.01, -0.02, 0.005]` | **список** — несколько значений по порядку |
| `{"US500": 0.048, "XAU": 0.069}` | **словарь** — значения по именам; `d["XAU"]` → 0.069 |
| `def sharpe(r):` … `return …` | **функция**: получает `r`, что-то считает, возвращает результат |
| `for t in range(260, T):` | **цикл**: повторить для каждого дня t от 260 до T−1 |
| `if pv > 0:` … `else:` | **условие** |
| `import numpy as np` | подключить библиотеку numpy под коротким именем `np` |
| `# текст` и `"""текст"""` | **комментарии** — Python их не выполняет, это пояснения для человека |

### numpy: массивы и срезы (главное в квант-коде)

```python
r = np.array([0.01, -0.02, 0.005])   # массив доходностей
r * 2          # каждый элемент × 2 → [0.02, -0.04, 0.01]   (без цикла!)
np.mean(r)     # среднее
r[0]           # первый элемент (счёт с нуля)
r[-1]          # последний
r[1:3]         # срез: элементы 1 и 2 (правая граница НЕ входит)
R[i, t]        # таблица: рынок i, день t
R[:, t]        # все рынки в день t
R[i, t-59:t+1] # рынок i, последние 60 дней включая сегодня
```

Правило: **срез `a:b` берёт от a до b−1**. Ошибка на единицу в срезе — частая причина «заглядывания в будущее».

## 3. Разбор на примере: Sharpe (`qm/risk.py`)

```python
def sharpe(r):
    r = np.asarray(r)                 # превратить что угодно (список, Series) в массив numpy
    sd = np.std(r, ddof=1)            # стандартное отклонение дневных доходностей
    return np.mean(r) / sd * np.sqrt(DAYS) if sd > 0 else 0.0
```

Читаем: среднее ÷ разброс, переведённое в годовые единицы (× √252). Если разброса нет (sd = 0) — вернуть 0, чтобы не делить на ноль.

## 4. Разбор на примере: один день бэктеста (`qm/portfolio.py`, функция `backtest`)

```python
r = np.sum(w * (R[:, t] + carry[:, t])) - np.sum(np.abs(w) * mk) / 252
```
**P&L дня** = Σ по рынкам: вес × (доходность сегодня + керри) − плата брокеру за перенос.
`w` — это веса, выставленные **вчера**. Сегодняшняя доходность умножается на вчерашние решения — так и должно быть.

```python
raw[i] = s / vol[i, t]
```
**Risk parity в одну строку:** сигнал делим на волатильность. Спокойный рынок (вол 10%) получает вдвое больший вес,
чем бурный (вол 20%), — риск у них одинаковый.

```python
port = raw[act] @ X
pv = np.sqrt(max(0.0, np.mean(port ** 2) - np.mean(port) ** 2) * 252)
k = target / pv
```
**Таргетинг волатильности:** считаем, как гулял бы портфель с такими весами за последние 60 дней (`pv`), и
масштабируем все веса так, чтобы ожидаемая волатильность = 10%. `@` — умножение матриц: веса × доходности всех рынков.

## 5. Чек-лист «где бэктест может врать» — ищи это глазами

1. **Заглядывание в будущее (lookahead).** Сигнал дня t должен использовать данные только до t включительно,
   а P&L — приходить с t+1. В нашем движке веса ставятся на закрытии t, а прибыль считается со следующего дня ✓.
   Ставки ЦБ берутся с задержкой 2 месяца (`rate_on` в data.py) ✓.
2. **Издержки.** Найди строки со `cost` и `markup`. Нет их — результат завышен. У нас: спред за изменение веса и плата за перенос ✓.
3. **Подгонка.** Сколько параметров (60 дней, 200 дней, 25%, 10%) и выбраны ли они **до** теста? Есть ли период проверки?
4. **Выжившие (survivorship).** Тестируем только рынки, которые дожили до сегодня? Для индексов не страшно, для акций — критично.
5. **Мало сделок / лет.** Посмотри на `t_stat`: |t| < 2 — результат может быть случайным.

## 6. Метрики риска — где они в коде

| Метрика | Функция | Что отвечает |
|---|---|---|
| Волатильность | `risk.volatility` | насколько гуляет результат за год |
| Sharpe / Sortino | `risk.sharpe`, `risk.sortino` | доход на единицу риска |
| Макс. просадка | `risk.max_drawdown` | самое глубокое падение от пика |
| VaR 99% | `risk.var_historical` | «в 99% дней теряем не больше X» |
| CVaR 99% | `risk.cvar_historical` | средняя потеря в худший 1% дней |
| Монте-Карло | `risk.bootstrap_drawdowns` | какие просадки могли быть при другом порядке дней |
