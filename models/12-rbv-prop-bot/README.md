
# 12 · RBV-бот для пропа (MT5, NextLevelFunded Instant Flex 10k)

**Статус:** 🟡 эксперимент на реальных правилах пропа · **Рынки:** NAS100, US500 (CFD) · 5m

> Модель RBV (папка 04) в советнике MT5 с защитами под правила фирмы. Преимущество не доказано (t ≈ 1.2,
> 7 месяцев данных, на крипте не работает) — это проверка вперёд с ограниченным убытком, а не «рабочая стратегия».

## Почему RBV, а не RB CE
RB CE («лимит в середину rejection block», модель 02) считался лучшим результатом исследования (+0.20R). При подготовке
бота выяснилось, что это **артефакт симуляции**: в 526 случаях одна свеча задевала и вход, и стоп, а бэктест считал
«стоп раньше входа — сделки нет». Вживую лимит исполняется по пути к стопу. С честным порядком RB CE = **−0.39R**.
RBV обрабатывает этот случай правильно с самого начала.

## Проверка под правила (`python models/12-rbv-prop-bot/prop_sim.py`)
| | Результат |
|---|---|
| RBV без фильтров объёма (как в MT5), издержки 0.6 б.п. | +0.22R на сделку, 180 сделок, t 1.2 |
| самая длинная серия стопов | 16 подряд |
| Instant Flex, риск 0.20%, дневной стоп 1%, лимит прибыли 1% | +4% раньше −4% во всех 42 стартах (без преимущества — 28%) |
| то же при риске 0.35% | 84% (без преимущества — 36%) |

Точка безубыточности по издержкам — около 1.2 б.п. (NAS100 при 27 600 ≈ 3 пункта спреда+комиссии).

## Правила фирмы → что зашито в советник
| Правило Instant Flex 10k | В советнике |
|---|---|
| статичная просадка 4% ($9 600) | общий стоп −3%: закрыть всё и остановиться до ручного сброса |
| дневная просадка 3% | дневной стоп 1% (от эквити/баланса на 17:00 NY) |
| консистентность 15% | дневной лимит прибыли 1%: закрыть всё и ждать следующего дня |
| максимальный риск 1% | риск 0.20% на сделку, лот по стопу; выше 1% советник не запустится |
| правило двух минут | тейк ставится через 130 с после входа, свои выходы — не раньше 130 с (стоп-лосс работает всегда) |
| минимум 10 сделок | ~25 сделок в месяц на двух индексах |
| советники, новости, выходные разрешены | по умолчанию новые входы блокируются за 5 мин до/после красных новостей США; позиции не держатся дольше 8 ч |
| антиспам | не больше 1 торгового запроса в секунду, не больше 10 сделок в день |
| мартингейл / сетки | нет: один сигнал = одна позиция с фиксированным риском, одна позиция на инструмент |

Случайной задержки «от детекта копирования» нет намеренно: модель своя, а маскировка поведения под проверки фирмы
сама может выглядеть как нарушение.

## Установка (`RBV_Prop.mq5`)
1. Скопируй в MT5: Файл → Открыть каталог данных → `MQL5\Experts`, скомпилируй (F7) или запусти, если уже есть `.ex5`.
2. Перетащи на любой график, вкладка «Входные»:
   - `InpAccountLogin` — **номер своего проп-счёта** (пока 0 — советник только пишет сигналы в журнал, без сделок);
   - `InpSymbols` — имена индексов у брокера (`NAS100,US500` или как в «Обзоре рынка»);
   - остальное — как проверено (риск 0.20%, стоп дня 1%, лимит дня 1%, общий стоп 3%).
3. «Разрешить алготрейдинг» + кнопка «Algo Trading». Журнал — вкладка «Эксперты» (строки `RBV: ...`).
4. Сначала стоит прогнать советника в тестере стратегий MT5 (NAS100, M5, «каждый тик на основе реальных тиков»)
   и неделю в режиме «только сигналы» (`InpAccountLogin = 0`).

Сброс после общего стопа: F3 (глобальные переменные) → удалить `RBV_HALT_<номер счёта>`.

_Исследование, не инвестиционный совет. Проп-фирмы работают только с 18 лет._
