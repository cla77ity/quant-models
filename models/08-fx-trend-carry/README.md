# FX trend + carry

**Статус:** 🔴 no edge (retail) · **Рынки:** 9 USD pairs + gold · daily · 2004–2026

> На розничном счёте тренд + керри −1.1% в год: свопы брокера съедают всё; тренд — страховка в кризисы.

## Правила
Тренд — среднее знаков доходности за 1/3/12 мес.; керри — лонг 3 валют с высокой ставкой, шорт 3 с низкой против USD;
размер по волатильности, портфель на 10% годовой волатильности, ребаланс раз в неделю, спред 1–5 б.п., своп-наценка 1%/год.

## Результат
| | В год | Sharpe | Просадка |
|---|---|---|---|
| тренд | −3.6% | −0.27 | −63% |
| керри | +0.1% | 0.06 | −41% |
| тренд + керри | −1.1% | −0.05 | −41% |
| золото, купить и держать | +9.2% | 0.58 | −47% |

Кризисы: тренд 2008 +12%, 2022 +17%; керри 2008 −16%, 2020 −12%. Отчёт: `results/step9_report.html`.
