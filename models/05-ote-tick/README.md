## Правила
Волна по тренду ≥ 3 ATR → обязательный CE 15m RB/OB/FVG у 0.62 / 0.705 / 0.79 + дисконт + ещё одно совпадение (второй CE,
открытие 00:00/09:30/10:00, неснятые лои); лимит на самом мелком уровне, в 9:30–10:00 — триггер 5m; стоп за началом волны;
5R, безубыток после внутреннего хая.
