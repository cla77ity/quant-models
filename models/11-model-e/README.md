# Model E — risk parity + SMA200 for a CFD broker

**Статус:** 🟢 live (demo) · **Рынки:** 7 index CFDs + gold + silver · daily · 2007–2026 · live on demo

> Улучшения (баланс классов, быстрый риск-контроль) подтвердились на 2017–2026, но реальные свопы брокера съедают ~4%/год.

## Правила
Risk parity по 7 индексам + золото + серебро, рынок ниже 200-дневной средней = 0, акции и металлы — равный риск,
10% годовой волатильности, ежедневная проверка, ковариация 60 дней, полоса 25% против мелких сделок, только лонги.
Разработка на 2007–2016, проверка на 2017–2026.

## Результат
| Условия | Sharpe | В год | Просадка |
|---|---|---|---|
| без наценки (фьючерсы / ETF) | 0.58 | +5.8% | −26% |
| наценка 2.5% (допущение) | 0.39 | +3.7% | −28% |
| **реальные свопы HeroFX** (лонг 7–12%/год) | **0.18** | +1.4% | −31% |

## Live (демо)

на демо / конкурсных счетах. Инструкция: `live/ИНСТРУКЦИЯ.md`.
