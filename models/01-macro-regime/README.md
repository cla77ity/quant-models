# Macro regime filter

**Статус:** 🟡 risk filter · **Рынки:** Nasdaq-100, S&P 500 · daily · 2008–2026

> Макро-счёт не предсказывает направление, но как фильтр риска улучшает Sharpe и режет просадку.

## Идея
10 макро-факторов (ликвидность ФРС, 10Y, доллар, VIX, 2Y против ставки, реальная доходность, инфляция, кредитный спред,
структура VIX, NFCI), каждый с задержкой публикации. Правила взяты из 2008–2016, проверка — 2017–2026.

## Результат (Nasdaq-100, 2017–2026, проверочный период)
| | В год | Sharpe | Просадка |
|---|---|---|---|
| Купить и держать | 20.8% | 0.94 | −35.6% |
| Тренд (цена > SMA50) | 13.0% | 0.91 | −19.4% |
| Тренд + макро-фильтр | 13.6% | **1.06** | −18.9% |

Доходность следующих 20 дней при счёте ≥ +3 и ≤ −3 почти одинаковая, ни один фактор отдельно не значим (|t| < 1.4).
